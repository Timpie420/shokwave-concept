# Shockwave

Telefoon = scherm. Sensoren zitten op de Arduino/ESP32-module op het board.

Live: https://shokwave-concept-timpie1.vercel.app

## Protocol
Module stuurt tekstlijnen, newline:

{"g":2.41}

of ax/ay/az in m/s2.

## Koppelen
BLE naam Shockwave, of WiFi ws://192.168.4.1/ws
Open site in Chrome op de telefoon. Telefoon mag in de zak.
